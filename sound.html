คู่มือใช้งานข้ามหน้าต่าง & สตรีมเสียงเข้าเกม / Discord

วิธีเล่นซาวด์เอฟเฟกต์ขณะเล่นเกม / ย่อเบราว์เซอร์ลง Taskbar ด้วย Gamepad:

บราวเซอร์ตระกูล Chromium (Chrome, Edge, Brave, Opera) มีฟีเจอร์มาตรฐาน Gamepad API ซึ่งยอมให้อ่านสัญญาณจอยเกมขณะเบราว์เซอร์อยู่ Background ได้โดยไม่มีข้อจำกัดด้านความปลอดภัยเหมือน Keyboard!

  1. เสียบจอยสติ๊ก / จอยเกม (Xbox, PlayStation DualSense/DualShock, Joy-Con หรือจอย USB ทั่วไป) เข้ากับคอมพิวเตอร์
  2. กดปุ่มใดก็ได้บนจอย 1 ครั้ง จะมีไฟสถานะสีเขียวขึ้นว่า 🎮 Gamepad Connected ที่มุมขวาบน
  3. กดปุ่มเปลี่ยน Hotkey บน Soundpad แล้วกดปุ่มจอยที่ต้องการ เช่น Gamepad_Btn_0 (ปุ่ม A/Cross) หรือ Gamepad_Btn_4 (ปุ่ม LB/L1)
  4. เมื่อตั้งค่าเสร็จ ย่อเว็บบราวเซอร์ลง Taskbar แล้วสลับไปเล่นเกม Fullscreen ได้เลย เมื่อกดปุ่มจอย ซาวด์เอฟเฟกต์จะดังทันที!
วิธีทำให้คนในเกม / Discord ได้ยินเสียง Soundpad จากเว็บ:

เนื่องจาก Soundpad เว็บเล่นเสียงออกมาทางลำโพงของคุณโดยตรง หากต้องการให้เสียงเปิดใส่ไมค์เพื่อส่งเข้าเกม ให้ทำตามขั้นตอนดังนี้:

  1. ดาวน์โหลดโปรแกรมฟรี VB-Audio Virtual Cable (VB-Cable)
  2. ตั้งค่าใน Windows Sound Settings: ให้ Soundpad เว็บนี้ส่ง Output ไปยัง CABLE Input (VB-Audio Virtual Cable)
  3. ใช้วิธี Listen to this device หรือใช้โปรแกรมผสมเสียง เช่น VoiceMeeter Banana / OBS Audio Mixer เพื่อรวมเสียง Mic จริงของคุณ เข้ากับ Virtual Cable ก่อนส่งเข้าเกมหรือ Discord
ทางเลือก: ใช้สคริปต์ AutoHotkey ส่งสัญญาณคีย์บอร์ด

หากไม่มี Gamepad สามารถใช้สคริปต์ AutoHotkey เพื่อส่งสัญญาณ Keyboard กดปุ่ม Numpad มาที่เว็บ Chrome/Edge ได้แม้ย่อหน้าต่าง:

AutoHotkey (AHK v2 Script) 
; AutoHotkey v2 Script - Forward Global Hotkeys to Web Soundpad
Numpad1::ControlSend("{Numpad1}",, "ahk_exe chrome.exe")
Numpad2::ControlSend("{Numpad2}",, "ahk_exe chrome.exe")
Numpad3::ControlSend("{Numpad3}",, "ahk_exe chrome.exe")
